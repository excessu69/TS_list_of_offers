# list of offers (React + TypeScript)

Приложение отображает список предложений Etsy.

## Демо

🔗 https://excessu69.github.io/TS_list_of_offers/

## Используемые технологии

- React
- TypeScript
- Vite

## Функциональность

- вывод списка товаров
- обрезка заголовка до 50 символов
- форматирование цены по валюте
- отображение количества товаров на складе
- изменение цвета бейджа в зависимости от количества
